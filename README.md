# SteamMewks Laboratory Archives

SteamMewksが制作してきたブラウザゲームの体験版・短編作品・試作版・旧版を保存、公開するためのGitHub Pages用リポジトリです。

完成した作品だけでなく、現在の作品へ至るまでの試作や、開発を終了した過去バージョンも、実際に遊べる開発記録として保存しています。

## 公開ページ

ルートの `index.html` が **SteamMewks Laboratory Archives** の入口になっています。

各作品はそこから個別に起動できます。

## 公開作品

### 夢幻ノ迷宮 ― 前日譚

`mugen-prelude/`

『夢幻ノ迷宮』本編へと繋がる前日譚。

短編の冒険として遊ぶことができ、クリアデータは『夢幻ノ迷宮』本編へ引き継ぐことができます。

---

### とらぶるしゅーたー DEMO

`troubleshooter-demo/`

『とらぶるしゅーたー』の体験版。

ゲームの世界観や基本的なプレイ感覚を体験できるデモバージョンです。

---

### プロト版 夢幻ノ迷宮

`proto-mugen/`

2025年に制作された『夢幻ノ迷宮』の初期試作版。

現在の『夢幻ノ迷宮』とはゲームシステムや内容が大きく異なります。

現在の作品へ至るまでの変化を残す、開発資料として公開しています。

---

### Simple Chess ― 旧版

`simple-chess/`

SteamMewksが過去に制作したブラウザチェス。

通常のチェス対局に加えて、ポイントを使用する変則モードやAIとのソロ対局を搭載しています。
初AI開発の末にチェックメイトがどうしても組み込めなかった。懐かしい。

現在開発している『機巧の遊戯卓』へ繋がる、過去の試作・開発記録として保存しています。

## Laboratory Archivesについて

SteamMewks Laboratory Archivesでは、完成した作品だけではなく、

- 体験版
- 短編作品
- プロトタイプ
- 旧バージョン
- 開発を終了した作品

なども保存しています。

ゲームは完成した瞬間だけが作品ではありません。

試行錯誤の途中で生まれたシステムや、後の作品へ受け継がれたアイデアも、SteamMewksの制作活動を形作ってきた記録です。

このリポジトリでは、それらを単なる資料ではなく、**実際に遊ぶことのできる開発記録**として公開していきます。
